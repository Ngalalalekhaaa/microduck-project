# 前滚翻头部俯仰反馈范围 · 2026-10-28

本次 Radxa 调整针对 `head_pitch`（当前机器舵机 ID 7）的**正向实际关节角保护上限**：前滚翻时从 96.875° 改为 **105°**，用于排查此前实测 99.404° 时提前卸力的问题。

配置在 `robot.json`：

```json
{
  "control": {
    "roulade_head_pitch_max_deg": 105.0
  }
}
```

这是已有 JSON 内增加的单个字段，不要用上面的片段覆盖完整标定文件。该字段缺省时仍用原上限 90° + 0.12 rad = 96.875°；当前实现允许明确设置在 96.87549354156988–110° 之间。

仅 `roulade` 模式的 `head_pitch` 正向上界读取这个配置。负向边界、其他关节、行走/坐站/俯身和 HOME 规则沿用各自原检查。该选项不修改训练模型、策略原始目标、HOME、舵机零位/方向或 EEPROM，编码器单圈约束、侧翻/角速度/IMU/反馈时效保护继续执行。新的越界日志会包含关节名、ID、实测角和允许范围。

**105°是本次软件试验上限，不是经过测量确认的机械安全范围。** 仍需确认头部不顶壳、不拉扯连接线；超过 105°仍会停。IMU 的 I²C 读失败是独立问题，不会因本次调整而消失。

本次用已保存的 99.404° 实机状态离线重放验证：原配置拒绝，105°配置通过；105.01°被拒绝。另验证所有其他关节及负向边界未放宽。部署验收只进行板端代码/配置检查，未自动驱动机器人。

关闭此放宽设置时，先停止按键流程和服务，再从 `robot.json` 删除 `control.roulade_head_pitch_max_deg`，或恢复此次生成的配置备份，随后重启 `microduck-xbox.service`。
