# 摆成直腿参考、记录刻度、缓慢移到训练 HOME

适用于部署包 **0.2.1**。此流程不需要舵机安装时的初始刻度。
只把标定存进 `robot.json`，不改舵机内部零偏、ID 或工作模式。

## 1. 这个“初始位置”具体指什么

本程序的 `straight` 是根据**本次训练使用的模型**计算的参考姿态，不是任意站姿：

- 托住躯干，使髋偏航轴竖直；腿的屈伸方向与机身前后方向一致，无内外八或侧倾。
- 从正侧面看，每条腿的髋俯仰轴 H、膝轴 K、踝轴 A，从上到下在同一竖直投影线上。
- 脚朝前，足部参考平面水平；原模型鞋底有曲面，不能拿任意一个凸点定义平面。
- 颈底与颈顶两个俯仰轴上下对齐，头朝前、水平、不歪。
- 左右都指机器人的左右；看的是实际转轴中心，不是舵机壳体中心或任意螺钉。

| 关节 | 左侧参考角 | 右侧参考角 |
|---|---:|---:|
| 髋偏航 | 0° | 0° |
| 髋侧倾 | 0° | 0° |
| 髋俯仰 | −58.411873° | +58.411873° |
| 膝 | −58.411873° | +58.411873° |
| 踝 | 0° | 0° |

颈俯仰、头俯仰、头偏航、头侧倾均为 0°。
精确值为 `atan2(35.7771,22)`；用 CPU 正运动学核对了 H/K/A、足部、颈和头的相对姿态。
结果见 [几何核对 JSON](直腿参考几何核对.json)。这只验证模型几何及角限位，不证明实机装配正确、路径无碰撞或能自行站稳。

**适用前提：你的实物转轴布置与这份训练模型对应。** 若飞特改件改变了连杆固定安装角或轴间几何，
应先核对 CAD。软件不会从舵机读数自动识别这些差异；不要用 `calibrate --pose zero` 保存上述直腿姿态。

## 2. 首次复制与准备

在训练电脑执行，替换用户名和 IP：

```bash
scp -r /home/luckysir/microduck/deploy_hd1910 用户名@RADXA_IP:~/
ssh 用户名@RADXA_IP
```

在 Radxa 执行：

```bash
cd ~/deploy_hd1910
bash install.sh
./run.sh init
./run.sh map-ids --profile servo_ids.user.json
./run.sh doctor
./run.sh scan
./run.sh inspect
```

`init` 保留已有 `robot.json`。更新部署目录不会自带另一台机器的配置；不要删除你已核对的配置。
`map-ids` 导入你提供的编号：左腿 1–5、颈和头 6–9、右腿 10–14，只修改本地配置，保留串口和 IMU 设置。
ID 变化的关节需重新确认方向，原零位标定失效；重复导入完全相同的 ID 保留已有标定。
串口、波特率须与本机一致；默认值只是安装参考。其它控制程序（如 robotd、servo-web）应停止占用此串口。
运动要求每颗舵机 `mode=4`、`angle_resolution=1`、明确的单圈硬件角限位；不会自动改写模式或角限位。

### 必须先核对 ID 与方向

托住机身后：

```bash
./run.sh relax
./run.sh watch --seconds 30
```

逐关节小幅转动，确认 ID，以及模型正方向运动时刻度增大还是减小，分别记录为 `1` 或 `-1`。
正方向表见 [零位标定操作步骤](零位标定操作步骤.md#2-确认-id-和正方向)。
例如仅当实际确认相符时：

```bash
./run.sh map-joint --joint left_hip_pitch --id 3 --direction -1
```

其他 13 个关节也需完成。不能用“都与别人一样”代替核对。改 ID/方向会使旧标定失效。

## 3. 记录你摆好的初始姿态

保持舵机通电、扭矩关闭；按第 1 节同时摆好并固定 14 个关节，执行：

```bash
./run.sh calibrate --pose straight
```

程序连续读取 12 组数据；任一关节变化超过 8 刻度会拒绝保存。保存内容包括：

- 当前各舵机刻度 `captured_ticks`。
- 完整参考角 `reference_q_rad`，不是全零。
- 对应的 ID 和方向快照。
- 换算后的软件 `zero_tick` 与训练 HOME 的 `home_ticks`。
- 标定时间；原配置保留为 `robot.json.bak.*`。

换算为：

```text
HOME刻度 = 参考姿态实测刻度 + direction × (HOME角 − 参考角) × 4096/(2π)
```

此命令没有目标、增益、扭矩或 EEPROM 写入。静止只证明读数稳定，不证明你摆的姿态正确。

## 4. 先看程序准备怎样移动

继续保持在直腿参考附近，执行：

```bash
./run.sh home-plan --from-pose straight --move-seconds 8
```

会逐行列出：`关节名 / ID / 当前刻度 / HOME刻度 / 当前角度 / HOME角度 / 移动角度`。
计划保存在 `logs/home_plan_*.json`。这是只读预览，不需要 IMU，不加载模型、不上力。

程序检查当前 14 个关节均在参考角 ±5° 内，标定记录与当前映射/零位一致，
起点和 HOME 在单圈 0..4095、舵机硬件限位和模型角限位内。
预览通过不代表真实机构没有碰撞，也不代表 IMU 已标定。

可以再做只读角度检查：

```bash
./run.sh watch --angles --seconds 20
```

在直腿姿态，左髋俯仰/左膝应约 −58.41°，右侧约 +58.41°。
保存后立即显示这些角度只是公式自洽，仍需按独立机械基准检查方向和摆放。

## 5. 缓慢移到训练 HOME

运动命令保留原有 IMU 检查。若还没核对 IMU，先按 [Radxa 与 IMU 接线](Radxa与IMU接线.md)
完成读取和三轴方向核对；只有确实同向时才保存单位轴映射，不要为了通过检查直接设置 verified。

```bash
./run.sh imu --seconds 20
```

固定、托住躯干，腿脚留足活动空间，撤掉会阻挡转动的定位尺和夹具。
保持在直腿参考附近，执行：

```bash
./run.sh home --from-pose straight --move-seconds 8 --seconds 3 --enable-motion
```

含义：

- `--from-pose straight`：使用已记录的直腿参考，只允许当前接近该参考时启动。
- `--move-seconds 8`：用 8 秒平滑移动到训练 HOME，可改为 8–30 秒。
- `--seconds 3`：到位后保持 3 秒。
- `--enable-motion`：本次明确执行运动，不设置开机自动上力。

开始前会静止校准 IMU 约 2 秒。程序先把目标预装成新读到的当前位置，并读回确认，再使能输出。
采用起止速度为零的三次平滑曲线；精确参考下的连续目标峰值速度约 10.90°/s，
此入口上限为 12°/s。刻度量化会造成单步差异，这些是目标曲线速度，不是实测轴速或硬件限速保证。
一次过渡目标发送完成后至少20ms再发送下一目标；8秒是计划时长下限，通信耗时可延长完成时间，
不会追赶补发加快动作。
纯回 HOME 不加载 ONNX、不执行行走策略。

途中保留反馈、倾角、温度、电压、时效和控制周期检查；反馈单次跳变超过 0.12 rad，
或与上一目标差超过 10°，会停止并尝试卸力。到位和保持要求在 HOME 容差内。
原有临时 RAM P=5、D=0、I=0 及退出恢复机制继续使用；不修改 EEPROM。

**结束后自动卸力，仍需托住。** `Ctrl+C`、停止信号或输入 `q` 回车可中断并尝试卸力；
机械卡住或总线失效时仍需可直接断开舵机电源，软件不能保证在断线后成功发送停止命令。
慢移轨迹与停止原因保存到 `logs/motion_*.session.json`。

## 6. 三条核心命令

前提：ID/方向已核对、已卸力，实物与训练几何对应；第三条还要求 IMU 安装方向已验证。

```bash
# 手动摆好直腿参考后，记录当前刻度
./run.sh calibrate --pose straight

# 只读预览，每颗舵机将从哪里移动到哪里
./run.sh home-plan --from-pose straight --move-seconds 8

# 支撑机身，8秒移到HOME，保持3秒，最后卸力
./run.sh home --from-pose straight --move-seconds 8 --seconds 3 --enable-motion
```

不要把这三条用 `&&` 串成自动上力的一条命令；预览后应查看目标和实物活动空间。

## 7. 常见拒绝信息

| 提示 | 处理 |
|---|---|
| 缺少 ID/方向映射 | 完成14个关节的 `map-joint`，不猜正负 |
| 缺少匹配的直腿标定记录 | 用当前映射重新 `calibrate --pose straight`；旧版没有映射快照的记录不能用于此入口 |
| 当前姿态偏离直腿参考超过5° | 卸力支撑，重新摆回参考；不要扩大普通启动角度限制 |
| HOME跨单圈边界 | 停止；该软件路径不跨圈，需另行核对安装/内部偏移，不取模、不让舵机绕圈找零 |
| 单圈硬件角限位不明确或超限 | 保留 `inspect` 输出核对，本程序不会自动解除硬件限位 |
| IMU尚未验证 | 按接线与方向文档完成实际核对；预览仍可使用 |
| 跟踪误差、未到HOME容差 | 查卡滞、方向、支撑、现有速度/加速度限制和增益；不要反复强行运行 |

普通 `home` 和 `run` 仍要求接近 HOME；`run` 不接受 `--from-pose`。
若上一条命令结束卸力后腿已垂落，下一次应重新摆到对应启动姿态。

本功能已做 CPU 几何验证和模拟接口测试；尚未在你的 Radxa/HD-1910 实机上运行。
