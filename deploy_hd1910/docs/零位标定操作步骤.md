# 已组装 Microduck 的零位标定操作步骤

本包使用软件零位：把关节摆到模型规定的已知角度，读取舵机刻度，存入 `robot.json`。
不要求把读数改成 2048，也不需要拆机重刷舵机。
本页解释 ZERO 标定。若要摆“侧面H/K/A轴心竖直”的直腿参考并自动移到HOME，
请使用 [直腿标定到 HOME](直腿标定到HOME.md)，该姿态要选择 `--pose straight`。

## 1. 支撑机身，关扭矩

确保已经完成主 README 的安装和通信检查，且没有其它程序占用串口。
保持舵机供电以读取编码器，托住或固定机身，再执行：

```bash
cd ~/deploy_hd1910
./run.sh init
./run.sh map-ids --profile servo_ids.user.json
./run.sh scan
./run.sh inspect
./run.sh relax
```

`map-ids` 导入你提供的编号，保留已有串口和 IMU 设置，不修改舵机内部 ID。
ID 变化的关节需重新确认方向，原零位标定失效；重复导入完全相同的 ID 保留已有标定。
`relax` 关闭配置中的14个关节扭矩。只有确认卸力后才轻轻手动转动；若关节仍顶住、
卡住或有阻力异常，先停下查原因，不要硬掰。关电后编码器无法读数，故标定时是“通电但卸力”。

## 2. 确认 ID 和正方向

打开只读刻度显示，轻轻移动一个关节，找出对应 ID：

```bash
./run.sh watch --seconds 30
```

**正方向表：**机器人自身的前、后、左、右；在模型 ZERO 附近，固定其它关节，只动这一轴。

| 关节 | 你提供的 ID | 模型角度增加时的动作 |
|---|---:|---|
| left_hip_yaw | 1 | 左脚足尖向机器人右方转 |
| left_hip_roll | 2 | 左腿下端向机器人左方摆 |
| left_hip_pitch | 3 | 左大腿下端向后摆 |
| left_knee | 4 | 左小腿下端向前摆 |
| left_ankle | 5 | 左脚足尖下压 |
| neck_pitch | 6 | 颈杆上端向后倾 |
| head_pitch | 7 | 低头 |
| head_yaw | 8 | 头向机器人左方转 |
| head_roll | 9 | 头的左侧下压 |
| right_hip_yaw | 10 | 右脚足尖向机器人右方转 |
| right_hip_roll | 11 | 右腿下端向机器人左方摆 |
| right_hip_pitch | 12 | 右大腿下端向前摆 |
| right_knee | 13 | 右小腿下端向后摆 |
| right_ankle | 14 | 右脚足尖上抬 |

编号来自你提供的记录；动作方向通过实际训练 XML 的正运动学核对，**不表示刻度一定增加**；
`direction` 正是用来连接这两个方向的。

按表中方向小幅移动约 3–5°：

- 刻度增加：`direction=1`。
- 刻度减小：`direction=-1`。
- 若刻度突然从 4095 附近跳到 0 附近，不按普通大小关系判断；本包不跨单圈边界取模，需先解决安装/内部偏移。

例如，固定颈部并让头朝前，确认 ID 8 后，看它向自身左转时的读数：

```bash
./run.sh watch --id 8 --seconds 20
```

若读数从 1900 降到 1843，说明这个关节的 `direction=-1`，保存：

```bash
./run.sh map-joint --joint head_yaw --id 8 --direction -1
```

这里的 `direction=-1` 只是读数下降时的示例，尚未在你的机器上实测。其它13个关节逐颗重复，按实际 ID 和方向写入。
`map-joint` 只保存映射，不驱动关节；改动映射后需要重新标定零位。

## 3. 摆成模型 ZERO 姿态

打开 [ZERO 正面](images/zero_front.png)、[ZERO 侧面](images/zero_left.png)、[ZERO 背面](images/zero_back.png)。
它们是14个关节角全为0的模型姿态，**不是 HOME 图**。

- 从正面检查左右对称、髋的偏航与侧倾、头部是否摆正。
- 从侧面检查髋、膝、踝之间的相对关系，以及颈部和头部俯仰。
- 看关节转轴和连杆的相对几何，不只看外壳轮廓。`q=0` 并不要求每块可见连杆都排成直线。
- 使用稳定支撑、直角尺/量角工具或匹配几何的夹具；眼看图片只能作粗调。
- 不要把“折到顶住零件”直接当成零位。HD 改件的接触点不一定等于原版接触角，且接触角还取决于其它关节姿态。

### ZERO 具体的机械关系

以下关系用本次训练 XML 的正运动学核对，长度指**旋转轴之间的关系**。先固定躯干，
让模型躯干的前后、左右基准保持水平；外壳任意一条边不一定是这个基准。

- **侧面看腿：**膝轴和踝轴上下对齐，间距 42 mm。髋俯仰轴在膝轴前方约 35.78 mm、上方 22 mm。
  因此大腿向后下方倾斜，不能把髋、膝、踝三轴拉成一直线。
- **正面看腿：**左右对称，不内外八、不侧倾；左右对应的髋俯仰、膝、踝转轴应横向对齐。
  不要求同一条腿外露的螺钉中心从正面排成一条竖线，因为安装件有横向错层。
- **脚：**脚朝躯干正前方，足部参考平面与躯干水平基准平行；鞋底网格有曲面，不用每个鞋底顶点判断水平。
- **颈：**颈底和颈顶两个俯仰转轴上下对齐，相距 50 mm。
- **头：**朝躯干正前方，既不低头、仰头，也不歪头。

侧视的腿轴心示意（前方在右；不是外壳轮廓）：

```text
                     ● 髋俯仰轴
                    /
                   /    髋在膝前 35.78 mm、上 22 mm
    膝轴 ●
         │ 42 mm
    踝轴 ●──── 脚朝前 →
```

这些数值适用于训练使用的原版轴间几何。若你的 HD 改件改变了轴间距或固定安装角，
需要核对 CAD 与训练模型，不能通过强行掰到图中位置补偿几何差异。

**当前命令一次捕获全部14个关节。** 采样时需要它们同时保持在规定姿态。
如果摆好一个、另一个就被重力压走，应先改支撑/夹具；不能将各关节先后摆过零位理解为已经同时完成标定。
原有内部偏移无需清除，软件会记录当前读数与模型零位的对应关系。

## 4. 保存零位

全部关节摆好并固定后执行：

```bash
./run.sh calibrate --pose zero
```

程序确认扭矩关闭、分辨率为1，连续读取12组数据。如果任一关节在采样期间变化超过8刻度，
会拒绝保存，提示固定姿态重试。稳定只说明没有移动，不说明角度一定摆对。

成功后 `robot.json` 每个关节都会有 `zero_tick`；零位姿态下，它就是这颗舵机的当前刻度。
不同舵机数值不同很正常。命令不会让关节自行移动，也不会写舵机 EEPROM。

## 5. 卸力状态下验证

本包0.1.1新增只读角度检查，不需要IMU、不推理模型、不发目标：

```bash
./run.sh watch --angles --seconds 30
```

显示格式：

```text
head_yaw ID=8 raw=1843 q=+5.01deg HOME_delta=+5.01deg
```

- `raw` 是舵机刻度。
- `q` 是按软件零位换算的模型角度。
- `HOME_delta` 是当前角度减去训练 HOME；在 ZERO 姿态下它通常不为0。

逐颗做两项检查：

1. 从零位小幅移动，再**根据尺子/夹具/相同机械基准**放回零位，`q` 应回到接近0。
2. 沿正方向移动一个已知小角度，例如量角器量得5°，`q` 应增加约5°；反方向应为负。

只看单颗时，例如：

```bash
./run.sh watch --angles --id 8 --seconds 30
```

刚保存后显示 `q≈0` 只证明计算与所保存读数一致，**不能独立证明真实零位摆对**。
如果保存时物理姿态错了，程序一样会把它显示成0；要用独立几何基准检查。

## 6. 最后才进入 HOME

关节标定检查完成后，按 [IMU 接线与方向说明](Radxa与IMU接线.md) 完成 IMU 方向验证。
托住机身，先摆到接近 [HOME](姿态与零位.md)，再执行：

```bash
./run.sh home --enable-motion --seconds 3
```

这一步会驱动舵机：约3秒移动到 HOME，再保持3秒，结束卸力，结束时仍需托住。
实际姿态应与 HOME 图片相符。若腿扭转、脚板翘起、头反向、单关节顶住，立即停止并复查 ID、方向和零位，
不要靠改 HOME 数字或增加增益掩盖标定错误。HOME 通过后才继续 `check` 和短时策略试机。

拆装舵盘、改硬件内部偏移、换舵机、改 ID 对应或方向后，要重新标定。
仅重启主板或舵机且机械/内部配置不变，不需要每次重做。
