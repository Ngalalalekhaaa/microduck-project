任务：`Mjlab-SitStand-Flat-MicroDuck-HD1910-Robust`。
从原始 `hd1910_sitstand_1699.onnx` 恢复 MLP 和输入归一化。
ONNX 没有价值网络、优化器、动作探索方差或归一化样本计数；这些状态重新初始化。
恢复前后用 128 组原始输入验证输出一致。归一化样本计数使用明确的 1000 万等效样本先验，
防止第一批新样本立即覆盖原来的均值/方差；该数字不是恢复出的历史计数。

策略接口仍是 50 Hz、61 维输入、14 维原始动作，目标为 `HOME + action`，不加动作滤波。
输入顺序为角速度(3)、重力方向(3)、编码器相对 HOME(14)、编码器差分速度(14)、
上次原始动作(14)、坐姿标志命令(3)、头部命令(4)、机身命令占位(6)。
坐姿标志 0=站立，1=坐下；部署不需要电流、质量、真实零位误差或其他特权信息。

新增独立配置，不修改旧坐站任务。迭代 0、500、1500、2500 逐级扩大随机化：

| 项目 | 初始范围 | 最终范围 |
|---|---|---|
| 躯干局部重心 x/y/z | ±12/12/6 mm | ±25/25/12 mm |
| 头部各部件局部重心 x/y/z | ±7/7/4 mm | ±15/15/10 mm |
| 全身统一质量与惯量倍率 | 0.95–1.05 | 0.8–1.2 |
| 头部额外质量与惯量倍率 | 0.95–1.05 | 0.75–1.3 |
| 每关节固定零位误差 | ±1.5° | ±5° |
| 左右脚独立接触摩擦系数 | 0.6–1.4 | 0.3–1.6 |
| 脚踝等效 P（名义 P=5） | 4.5–4.75 | 4.0–4.75 |
| 其他关节等效 P | 4.75–5.25 | 4.0–6.0 |
| BAM 齿轮摩擦倍率 | 0.85–1.15 | 0.6–1.4 |
| 空载供电 | 7.0–8.4 V | 6.4–8.4 V |
| 负载压降增益 | 0–0.2 V/Nm | 0–0.35 V/Nm |
| 压降后的电压下限 | 6.5 V | 5.8 V |
| 动作延迟（每步 5 ms） | 2–6 步 | 1–8 步 |

另保留 IMU 安装误差/噪声、转子惯量 0.8–1.2、力矩上限 0.9–1.0 和小幅外推扰动。
电压/压降范围是训练假设，尚未通过电气参数辨识。头部倍率与全身倍率相乘，
所以最终实际总质量范围还受头部占比影响，并非严格 ±20%。

零位偏差每回合固定，同一个 bias 同时参与 `q_reported=q_true+bias` 与
`q_target_true=HOME+action-bias`。初始姿态噪声独立存在。
所有惯性随机化从编译默认值重新施加，质量与绕重心惯量同比缩放，不随回合累计。
脚踝 P 是 BAM 连续等效增益；真机使用该模型前需配套设置脚踝较低增益，并确认寄存器语义。

倾斜角 `theta=acos(-gravity_z)` 使用真实机身姿态，每个控制周期都计算，
不受站立/坐下命令、机身高度、接触状态或过渡阶段门控。
令 `e=max((theta-15°)/10°,0)`，新增奖励为 `-8*(e+e²)`。
按用户要求，**超过 35° 判失败**，非超时失败额外奖励 `-500`（奖励管理器会乘控制步长）。
该阈值约束训练回合，不能单靠训练惩罚保证真机永远不越界。
保留原姿态/高度/静止/复合跟踪和温和运动奖励，逐级增大动作变化惩罚以抑制抖动。
