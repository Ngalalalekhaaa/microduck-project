# HD-1910 与原版训练参数对照

核验日期：2026-09-28。以下描述已经完成的四次训练；没有为本次核验修改训练参数或重新训练。

## 结论

HD-1910 两版在官方 Microduck 步行任务上替换了执行器动力学、控制器和供电范围，
并补上飞特控制器目标位置历史的初始化与分环境重置。
对应平地版、齿隙版的奖励、命令、课程、PPO、观测与随机化设置保持一致。
四版都是独立从随机策略训练，没有用 XL330 检查点微调 HD-1910。

HD 参数来自公开的 1910 辨识文件，尚未用这台 HD-1910 / Radxa / HAT 整机做参数辨识。
参数来源及固定版本见 [1910 参数来源](../microduck_rl_hd1910/src/mjlab_microduck/robot/hd1910/README.md)。

## 1. 执行器配置

| 设置 | 原版 XL330 | HD-1910 |
|---|---|---|
| 动力学模型 | BAM 内置 XL330 M6 | LuwuDynamics 1910 M6 JSON |
| 固件控制器实现 | XL330 | BAM 的飞特 `STS3215Actuator` |
| 固件比例增益 `kp_fw` | 200 | 5 |
| 初始供电采样 `vin_range` | 6.5–8.2 V | 7.4–8.0 V |
| 负载压降增益 | 0–0.2 V/(N·m) | 相同 |
| 压降后的电压下限 `vin_min` | 6.0 V | 7.0 V |
| 控制器 PWM 占空比上限 | 1.00 | 0.97 |
| BAM 模拟的固件限流 | 默认 1.75 A | 未建模电流限制 |
| 执行器命令延迟 | 3–6 个物理步，即 15–30 ms | 相同 |
| 主动关节 | 14，排除 `passive_*` | 相同 |

供电与压降增益在环境初始化时采样，随后供电随负载压降变化；不是每步重新抽取电池电压。
HD 版并非固定 7.4 V，当前范围也不是这台电池、HAT、线束的实测覆盖范围。

`kp_fw=200` 和 `kp_fw=5` 属于不同固件控制律及数值尺度，不能理解为 HD 刚度只有原版的 1/40。
`actuator: "sts3215"` 选择飞特控制器实现，实际电机参数使用 `1910_m6.json`。
飞特的目标历史修复位于 [feetech_bam.py](../microduck_rl_hd1910/src/mjlab_microduck/actuator/feetech_bam.py)，
用于避免首次计算及环境重置时沿用错误的目标位置；没有给策略动作新增 EMA 低通滤波。

限流差异由实际 BAM 控制器类的默认行为引入。原版配置中的 `# max_current=1.75` 是注释，
并未关闭 XL330 类默认的 1.75 A PWM 限流。HD 控制律没有对应分支；这不表示真实 HD 舵机没有保护机制。
本次已用实际任务配置构造执行器，在 CPU 上核对这两个默认值。

配置证据：[XL330](../microduck_rl/src/mjlab_microduck/robot/microduck_constants.py)、
[HD-1910](../microduck_rl_hd1910/src/mjlab_microduck/tasks/microduck_hd1910_env_cfg.py)。

## 2. 普通版与齿隙版

两个舵机系列采用同样的版本划分：

- 普通版没有额外的被动齿隙关节，但仍有摩擦、观测噪声、延迟与参数随机化。
- 齿隙版在 14 个主动关节后各加入 ±1° 的被动关节，总间隙 2°。
- 齿隙版的编码器位置按主动关节角与齿隙角之和计算；观测与相关奖励的关节选择随之调整。
- 摩擦与反电动势使用电机侧速度；没有把被动齿隙关节当成额外的策略动作。
- ±1° 间隙和编码器位于间隙输出侧均是模型假设，尚未在用户机器上验证。

因此这里的“齿轮误差版”具体模拟机械齿隙。固定零位误差、传动弹性、装配误差不是同一个物理量。
两版另有相同的编码器偏置随机化 ±0.015 rad（约 ±0.86°）。

## 3. 其他训练设置

### 四版之间保持一致

| 设置 | 四版实际值 |
|---|---|
| 并行环境 / 训练轮数 / 种子 | 2048 / 4000 / 42 |
| 每环境每轮采样 | 24 步；每版总计 196,608,000 条环境步样本 |
| 物理步长 / 策略周期 | 5 ms / 20 ms，即策略 50 Hz |
| Actor 输入 / 动作 | 61 / 14；位置动作，缩放 1.0 |
| Actor、Critic 隐藏层 | 512、256、128；ELU；启用观测归一化 |
| PPO | 5 次更新遍历，4 个 minibatch，初始学习率 0.001，自适应调整 |
| PPO 其他设置 | clip 0.2，熵系数 0.01，gamma 0.99，GAE lambda 0.95，目标 KL 0.01 |
| 检查点 | 每 250 轮保存，最后为 `model_3999.pt` |
| 初始化 | 各自从随机权重开始，未启用 resume / warm start |
| 机器人几何与 HOME | 对应普通/齿隙模型相同；未按 HD 整机重新建模质量、惯量、重心 |

保留的训练内容包括：

- 线速度范围 `vx=±0.4 m/s`、`vy=±0.3 m/s`；转向范围 `wz=±1 rad/s`。
- 线速度跟踪权重 2.0、标准差参数 √0.1；角速度跟踪权重 2.0、标准差参数 √0.5。
- 动作变化惩罚从 −0.1 按课程增强到 −1.0（1500 轮）；站立指令比例从 2% 增至 25%（2000 轮）。
- 质量和惯量随机化 ±5%，BAM 非黏性摩擦幅度和转子等效惯量随机化 ±10%。
- 头部/躯干重心随机化及课程、外部推力、IMU 安装角与观测噪声随机化。
- Kp/Kd 随机化、关节阻尼随机化和对称损失仍关闭。

**此前讨论的增加低速指令采样、修改低速奖励、减弱动作惩罚或放慢课程均未用于这四版。**
不能将 HD 版表现差异归因于这些尚未实施的改进。

## 4. 尚未按实机校准的部分

HD 改动没有包含 Radxa、HAT、电池布线或 LSM6DSV16XTR 的专门辨识数据。
整机连杆质量与惯量仍来自原版模型；BAM 的电机等效惯量虽已替换，二者不能混为一谈。

关节速度观测仍固定延迟 1 个策略周期（20 ms），上游这一假设来自 Dynamixel 速度反馈；
IMU 观测仍延迟 0–1 个策略周期（0–20 ms）。这些设置直接继承，未用飞特总线或 Radxa 直连 IMU 测量结果替换。
IMU 安装角随机化最多 6°，角速度噪声 ±0.03、投影重力噪声 ±0.01；实际安装坐标和系统性偏置仍需标定。

这些模型可用于后续实机适配和验证，但其参数不能视为已经对应到本机的最终部署配置。
