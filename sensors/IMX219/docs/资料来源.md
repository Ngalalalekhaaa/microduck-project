# IMX219 资料来源、固定版本与许可

更新：2026-11-05。部署入口见[README](../README.md)，实测边界见[问题与排查](问题与排查.md)。本包针对 **IMX219 / Raspberry Pi Camera V2 兼容模组 + Radxa ZERO 3W / RK3566 + vendor 6.1 内核**；实际核对内核为 `6.1.115-vendor-rk35xx`。其他镜像、内核、模组先做适配核对，不能仅凭传感器型号相同套用全部设置。

包名包含 rk3568，但其描述指向 RKISP v21 / RK3566 与 RK3568；不能只看文件名认定它不适用于 ZERO 3 的 RK3566。

IQ 来源为 [Radxa rockchip-iqfiles 仓库](https://github.com/radxa-pkg/rockchip-iqfiles)，[0.1.16 发布记录](https://github.com/radxa-pkg/rockchip-iqfiles/releases/tag/0.1.16)，源码提交 `4c2e2e0234dfc3eb164d6b273c4c35b5409fe189`。原件安装路径：

```text

```

运行配置是其独立副本：

```text
/etc/iqfiles/imx219_rpi-camera-v2_default.json
```

本包仅作以下修改，不手动重调 AWB、颜色矩阵、Gamma 数值：

1. `AECV2_STRATEGY_MODE_LOWLIGHT_PRIOR` → `AECV2_STRATEGY_MODE_LOWLIGHT`。
2. `CALIB_AWB_HDR_FRAME_CHOOSE_MODE_AUTO` → `CALIB_AWB_HDR_FR_CH_AUTO`。
3. `ae_calib.CommCtrl.Enable` 从 1 改为 0，由抓帧脚本接管曝光。

## 4. 内核接口兼容源码

使用 Pollen Robotics Microduck 的 [`scripts/rkaiq-modinfo-shim.c`](https://github.com/pollen-robotics/microduck/blob/a9ec4b2079ef8ee7904014089c885bb07d57d63c/scripts/rkaiq-modinfo-shim.c)。本地上游快照提交为 `a9ec4b2079ef8ee7904014089c885bb07d57d63c`，文件 SHA256：

```text
f78344c0346bf3a67890d3c01197995cc76fbce554c59da1ea7f651a2290cb6b
```

该兼容层只在 `rkaiq_3A` 进程中拦截查询模组信息的 ioctl，处理旧引擎与 vendor 内核结构体大小差异，帮助选择正确 IQ 文件。它不是 IMX219 内核驱动，也不改变传感器曝光寄存器。需要在目标 aarch64 板上用 gcc 编译，不能把电脑的 x86 `.so` 直接复制到板上。

上游 `setup-rkaiq.sh` 可用来理解原始 `mediad` 集成，但本包使用 `scripts/setup_isp.py` 作为单帧方案安装入口；不同时运行两套安装路线。

持续录像/实时预览的上游代码：[mediad 源码目录](https://github.com/pollen-robotics/microduck/tree/a9ec4b2079ef8ee7904014089c885bb07d57d63c/mediad)。
其摄像头采集、曝光循环、WebRTC 和机器人服务有共同依赖，不能只复制一个 Rust 文件便启动。
本机完整源码快照保存在 `archive/legacy-code/upstream-mediad/`；旧混合媒体代码也在该归档的上级目录。
本次可独立部署并验证的接口是单帧拍摄回传；接回上游实时流前，需统一曝光控制者和 ISP 服务配置。

目录用途：

```text
scripts/                    当前维护的部署、诊断、抓帧入口
vendor/                     运行所需上游兼容源码和许可
references/                 来源清单与资料下载入口
packages/                   原始 .deb 缓存（公共 Git 忽略）
evidence/verification.json  去标识实测摘要

```

完整现场归档可能含网络信息和个人场景，默认不放入部署包或 Git。公开源码和同事部署包应使用同一套 `scripts/`，旧试验脚本保留用于解释历史问题，不作为新的部署入口；尤其不要执行旧现场脚本中的固定用户目录、自动重启、驱动解绑/重绑操作。
